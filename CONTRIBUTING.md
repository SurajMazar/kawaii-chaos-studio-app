# Contributing

Thank you for wanting to help! This project is **open source but not open to outside pull requests**: changes to this
repository are made by its maintainer only. Pull requests from other accounts are closed automatically.

What you can do:

- **Fork it** and change anything you like in your fork — the MIT licence allows it (keep the copyright notice).
- **Report a bug or ask for a feature** in Issues: what you did, what you expected, what happened, your macOS version
  (or browser), and a screenshot if it helps.
- **Share your fork** — if a change would help everyone, describe it in an issue and link your fork.

Security problems: please do not open a public issue; use GitHub's *Report a vulnerability* (Security tab) instead.
